# Conventions

- **Bible = world rules only.** Character- or storyline-specific details (e.g. Ship's golden-door portal entrance) go in the storyline file, not the bible.
- **Canon** (Scott, 2026-10-12): planar systems, villains and gadgets invented for a story live in that storyline's file. They move into the bible's *Known planar systems* only once Scott declares the story canon.
- **Storylines file**: `storylines.md` holds guidance for every storyline, open world questions, hooks, and a section per format listing its storylines.
- **Episode file naming** (Scott, 2026-10-31): kept episodes go in `storylines/<name>/episodes/NN-title-slug.md`; candidate drafts go in `storylines/<name>/drafts/NN-model.md` (add `-b`, `-c` for more drafts from one model). A picked draft moves to `episodes/` and a relative symlink to it takes its place in `drafts/`, so the kept episode is a real file whose GitHub raw URL works (raw URLs don't follow symlinks).
- **Storyline file naming** (Scott, 2026-10-31): `storylines/<name>/storyline.md` (was `<name>/<name>-storyline.md`; never `-setting.md`).
- **Formats** (Scott, 2026-10-12; episodic added 2026-10-25): short form (up to ~15k words), episodic (series of short form episodes with arcs; Astral Trek is the first), long form (novella/novel), adventure (playable D&D module, 1-3 sessions), campaign (long playable arc).
- **Terminology** (Scott): say "whole soul", never "un-sundered".
- **Travel terms** (Scott): *shifting* = instant move between ships and/or planes; *teleporting* = instant move within one plane or ship; *portaling* (aka dimension door) = opening a walk-through passage between ships and/or planes.
- **Open questions** in `storylines.md` are deliberately left for a story to answer; when one is settled, record it in the bible.
